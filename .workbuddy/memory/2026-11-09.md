**用户拍板的三项决策**
1. 模型全部走远端 DeepSeek V4.1F API（能推理、成本低）。跑几天若真贵再拆部分给本地小模型。
2. 第一版只做**自主循环**，不做被动唤醒。
3. 暂不复用现有 Electron + OneBot 项目；人机即时互动优先级低。以后可能复用。

**v0.2 的关键设计决定（与 v0.1 的实质差异）**
- 新增「空转」通道：`action=none` 只落 heartbeat，**绝不写情景记忆**（I1 不变量）。防止幻觉事件递归污染记忆。
- 心情拆两组：情绪（energy/valence，向 baseline 回归）+ 驱动（boredom，不回归、随时间累积，被新体验消耗）。模型只输出 delta(-10..10)，服务端 clamp 到 [5,95]。
- 删除 v0.1 的「成功率下降」硬约束，只保留可见性过滤。随机失败是白噪声，会让「被驱动 vs 表演」无法区分。
- 区分 tick（60s，不调 LLM）与 wake（烧 token 的思考）。
- 核心记忆每 20 次 wake 自省重写，但 diff 相似度 < 0.75 则拒绝（限制漂移速度）。
- 第一版工具：read_feed / write_journal / recall。强制 summary/detail 分离。

**成本实测估算**：单次 wake ≈ 2950 输入 + 300 输出 token；30 次/天 → 月 ¥5-15。结论：成本不构成约束，不必为省钱牺牲设计。

**观测核心指标**：心情(valence 3 档) 与工具选择的互信息。≈0 说明在表演；0.05-0.3 为健康区间；>0.5 说明自主性是假的。

**待用户拍板**：① 语言（暂定 Python 3.11，用户有 Electron/TS 背景）；② 世界输入源（RSS 等，不填则鱼鱼无内容可看）；③ self_review 触发频率。

## 21:30 两段式唤醒改造（v0.3 核心）

**起因**：21:07 那次唤醒，她的思考过程里出现「这是意图，但好像没执行？」——上下文只给了意图，没给事实。根因三处：
1. `prompt.py` 组装【最近在做的事】只用了 `why`+`tool`，`result_summary` 查出来了却被丢弃。
2. `memory` 与 `felt_delta` 在**看到正文之前**就写死了：memory 只能写标题，felt_delta 只是预期。03 次唤醒甚至交了白卷（memories 从 id4 直接跳到 id5）。
3. `index 0` 不是最新：inbox 的 ts 是抓取时间，同批相同，排序退化成 id；feed 按「新的在前」插入 → id DESC 拿到的是最旧那期。prompt 说 418，她点开是 416。

**改动**：
- `prompt.py`：DECIDE_CONTRACT（去掉 memory）/ REACTION_CONTRACT + `build_reaction_messages()`（换 system 契约、保留 world context、喂正文前 2000 字并明说截断）；【最近在做的事】改为渲染 `result_summary`，why 降为旁注。
- `brain.py`：新增 `Reaction` / `react()` / `_parse_reaction()` / `_clean_felt()`；`_call_api` 加 `kind` 参数（decision/reaction）；`Decision` 删掉 memory 字段（死字段是隐患）。
- `scheduler.wake`：分叉判据 `result.ok and result.detail.strip()`——**不预测决策，看结果有没有内容**；成功走第二段并用后果覆盖 felt_delta/memory/next_wake，失败与空转只走一段；token 两段累加。
- `tools._plain()`：剥 HTML 标签 + `html.unescape`；read_feed 排序改 `ORDER BY id DESC`。
- `feed.py`：批量插入前 `reversed()`，让 id 与时间同向；Atom 优先 `<content>`（阮一峰 summary 只有 24 字，content 13.7KB）；RSS 支持 `content:encoded`；插入后带一条「正文变长就地更新」的自愈 UPDATE。
- `trace.py` 查看器支持 reaction 段，打印标注「第一段 决策 / 第二段 反应」。

**验证**：三条分支都用假客户端跑过（成功=2 次调用、失败=1 次、空转=1 次且不写记忆）；真实库 24 条 inbox 原地重排（未清库，因 config 只开了知乎源，清空会永久丢阮一峰 3 篇）；阮一峰 3 篇正文由 24 字补全到 6000 字；单测 10/10 绿。
